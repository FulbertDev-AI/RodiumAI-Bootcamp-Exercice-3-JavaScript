# Mon Projet JavaScript - API RodiumAi (avec SDK)

Script interactif en Node.js (v18+) utilisant le package npm `rodiumai` pour réaliser les étapes de chat, image et vidéo.

> La génération vidéo n'est pas encore prise en charge par la version actuelle du SDK RodiumAI. L'étape vidéo affichera un message explicite jusqu'à ce que la fonctionnalité soit publiée.

## Installation
1. Installez les dépendances :
   ```bash
   npm install
   ```
2. Copiez `.env.example` vers `.env`, puis renseignez votre clé API RodiumAI.

3. Lancez le script :
   ```bash
   npm start
   ```
